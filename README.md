# BOMwise

## Hi — I'm Bianca 👋

I'm an engineer and the founder of **[BOMwise](https://bomwise.io)**,
an AI tool that reviews electronics Bills of Materials to surface:

- 🔁 drop-in equivalents and alternates
- ⚠️ lifecycle risk (NRND, obsolete, single-source)
- 💰 cost-reduction opportunities on commodity lines

### What I'm doing on GitHub

Mostly reading other people's hardware projects to learn what real BOMs look
like in the wild — open-source hardware communities are the best dataset for
this. If I open an Issue on your repo, it's usually because I've run your BOM
through BOMwise and found something worth sharing.
